# moleclub

A cute, minimalist Whack-a-Mole arcade game made for quick breaks. Built with pure HTML, CSS, and vanilla JavaScript — no dependencies or build tools needed.

## Features

- **Illustrated SVG moles & burrows**: Custom cartoon moles with layered dirt burrows and grass tufts for realistic depth.
- **Micro-animations**: Smooth spring popups, idle eye blinking, squash reaction on hit, floating `+1` indicators, and particle bursts.
- **Difficulty modes**: Choose between **Easy**, **Medium**, and **Hard** with tailored mole speeds and high score tracking per difficulty.
- **Game over card**: Clear, clean results overlay popping up over the board with your score, personal best, and an instant replay button.
- **Built-in sound effects**: Procedural cartoon audio synthesized with the Web Audio API, plus an on-screen mute toggle.
- **Arcade gameplay**: 30-second timer, progressive speed scaling as your score climbs, and high scores saved in `localStorage`.
- **Responsive & accessible**: Optimized for both mobile and desktop with keyboard support (`Tab` + `Space` / `Enter`).

## How to play

Simply open `index.html` in any browser, pick a difficulty, hit **Start game**, and tap as many moles as you can before time runs out.
